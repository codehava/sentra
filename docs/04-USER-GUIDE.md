# User Guide - SENTRA

## Getting Started

### Login

1. Buka aplikasi SENTRA
2. Masukkan **NIP** dan **Password**
3. Klik **Masuk**

> Jika ini login pertama, Anda akan diminta untuk mengubah password.

### Change Password

1. Masukkan **Password Baru** (minimal 6 karakter)
2. Konfirmasi password
3. Klik **Ubah Password**

---

## Dashboard

Dashboard menampilkan:
- **Statistik** transaksi (total, pending, approved, rejected)
- **Recent Transactions** yang perlu ditindaklanjuti
- **Quick Actions** untuk akses cepat

---

## Create Transaction

### Step 1: Pilih Jenis Transaksi

Klik menu **Create** di sidebar, lalu pilih jenis transaksi:
- Beban Usaha (BU)
- Pengadaan Barang (PB)
- Dll.

### Step 2: Isi Form

Lengkapi field yang tersedia:
- **Field Wajib** ditandai dengan (*) 
- **Field Unique** akan divalidasi untuk mencegah duplikasi

### Step 3: Upload Dokumen (Opsional)

Klik area upload atau drag & drop file.

### Step 4: Submit

Klik **Submit** untuk membuat transaksi.

> Transaksi akan mendapat nomor tiket otomatis, contoh: `BU-20260105-0001`

---

## My Tasks

Menu **Tasks** menampilkan transaksi yang perlu Anda proses sesuai role:

### Actions

| Action | Description |
|--------|-------------|
| **Approve** | Setujui dan lanjutkan ke stage berikutnya |
| **Reject** | Tolak transaksi (selesai) |
| **Return** | Kembalikan ke stage sebelumnya untuk perbaikan |

### Process Transaction

1. Klik transaksi di list
2. Review detail dan dokumen
3. Isi catatan (optional)
4. Klik action yang sesuai

---

## My Tickets

Menu **My Tickets** menampilkan transaksi yang Anda buat.

### Status

| Status | Color | Description |
|--------|-------|-------------|
| DRAFT | Gray | Belum submit |
| PENDING | Yellow | Menunggu approval |
| APPROVED | Green | Disetujui |
| REJECTED | Red | Ditolak |
| RETURNED | Orange | Dikembalikan untuk perbaikan |

### View Detail

Klik transaksi untuk melihat:
- **Form Data** - Data yang diinput
- **Documents** - File yang diupload
- **History** - Timeline persetujuan

---

## User Profile

### Access Profile Menu

### Menu Options

| Menu | Description |
|------|-------------|
| **Ubah Password** | Ganti password Anda |
| **Logout** | Keluar dari aplikasi |
